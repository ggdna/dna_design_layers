# راهنمای دامنه

لایهٔ ۲ از ۷، فضای مسئله. مهارت: `/layers-domain`.

## @layer بدانید این لایه چیست <a id="know-what-this-layer-is"></a>

- آنچه پیش از هر محصولی در دنیای واقعی وجود دارد: مفاهیم، اصطلاحات،
  فرایندها، مدل‌های ذهنی
- مشاهده، نه طراحی

## @decide تصمیم بگیرید <a id="decide"></a>

- کدام مفاهیم کلیدی وجود دارند و چگونه به هم مربوط‌اند
- مردم چه واژه‌هایی به کار می‌برند، و کجا این واژه‌ها با هم تعارض دارند
- مرزها کجاست: گروه‌هایی که یک واژه را به شکل متفاوت به کار می‌برند
- کدام رویدادها و فرایندها دامنه را در گذر زمان ساختار می‌دهند

## @honest صادق بمانید <a id="keep-it-honest"></a>

- تناقض‌ها را ثبت کنید، حلشان نکنید؛ حل کردن به مدل مفهومی تعلق دارد
- در دنیای واقعی بمانید؛ در برابر صحبت از محصول یا رابط کاربری مقاومت
  کنید
- اسم‌ها را به‌صورت شیء / ویژگی / نمونه / نامشخص علامت بزنید، کم فیلتر
  کنید
- اگر به‌جای واقعیت پژوهش‌شده باورهای تیم را ترسیم می‌کنید، آن را بگویید

## @technique یک تکنیک برگزینید <a id="pick-a-technique"></a>

| موقعیت                              | تکنیک                                  |
| ----------------------------------- | -------------------------------------- |
| روابط نامشخص                        | نقشهٔ مفهومی (`graph TD`)              |
| زبان مورد مناقشه                    | بازبینی اصطلاحات                       |
| گروه‌ها واگرا هستند                  | نقشه‌برداری bounded context            |
| دامنهٔ فرایندمحور                    | طوفان رویدادهای دامنه (event storming) |
| دانش در ذهن افراد است               | مصاحبه با خبرگان، همراهی (shadowing)   |
| دامنه فرم و فاکتور تولید می‌کند      | تحلیل اسناد و مصنوعات                  |
| بازار جاافتاده                       | تحلیل رقبا                             |

## @capture ثبت کنید <a id="capture"></a>

- نقشهٔ مفهومی، اگر جایگاه خود را به دست آورده باشد
- تعارض‌های اصطلاحات و bounded contextها
- رویدادهای کلیدی
- برداشت اسم‌ها (noun harvest)

## @continue ادامه دهید <a id="continue"></a>

برداشت اسم‌ها مادهٔ خام [مدل مفهومی](conceptual-model-guide.md) است.
