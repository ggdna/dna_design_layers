# راهنمای سطح

لایهٔ ۷ از ۷، فضای راه‌حل. مهارت: `/layers-surface`.

## @layer بدانید این لایه چیست <a id="know-what-this-layer-is"></a>

- جایی که همهٔ لایه‌های زیرین به آنچه یک فرد با آن روبه‌رو می‌شود تبدیل
  می‌شوند: واژه‌ها، تصاویر، حرکت، بازخورد
- مشکلات سطح اغلب نشانه‌های لایه‌های عمیق‌ترند

## @decide تصمیم بگیرید <a id="decide"></a>

- آیا سطح به واژگان و اشیای مدل وفادار است
- آیا همهٔ امکان‌های کنش (affordances) در طرح اولیه (breadboard) حاضرند و
  هیچ چیز بدون مدلی در پشتش وجود ندارد
- آیا لحن عاطفی با کارهای (jobs) کاربران سازگار است
- کاربران چگونه می‌فهمند چه اتفاقی افتاد، چه چیزی در جریان است یا چه
  چیزی شکست خورد
- چه چیزی برجسته‌تر از همه است، و آیا باید باشد
- آیا همه چیز برای کاربرانی که به آن نیاز دارند دسترس‌پذیر است

## @honest صادق بمانید <a id="keep-it-honest"></a>

- اصلاحات سطحی را از مشکلات عمیق‌تر جدا کنید؛ مشکلات عمیق‌تر را به لایهٔ
  خودشان برگردانید
- اصطلاحات با زبان فراگیر (ubiquitous language) مطابقت دارند
- نه شیء تغییرشکل‌دهنده (shapeshifter)، نه شیء پنهان‌شده
- پیام‌های خطا تشخیص می‌دهند، توضیح می‌دهند و راه بازیابی ارائه می‌کنند
- برجستگی بازتاب اهمیت است
- دسترس‌پذیری تصمیم‌گیری می‌شود، نه اینکه به پیش‌فرض‌ها واگذار شود

## @technique یک تکنیک برگزینید <a id="pick-a-technique"></a>

| موقعیت                          | تکنیک                                              |
| ------------------------------- | -------------------------------------------------- |
| اصطلاحات نادرست به نظر می‌رسند  | بررسی واژگان                                       |
| یک شیء ظاهر متفاوتی دارد        | بررسی سازگاری اشیا                                 |
| چیزی کم یا زیاد است             | بررسی کامل‌بودن در برابر breadboard                |
| لحن ناهماهنگ است                | بررسی لحن عاطفی                                    |
| کاربران مطمئن نیستند چه شد       | فهرست بازخوردها و خطاها                            |
| رقابت بیش از حد                 | بازبینی سلسله‌مراتب                                 |
| واگذارشده به پیش‌فرض‌ها           | مرور دسترس‌پذیری                                   |
| تولید سطح                       | ماکاپ‌ها، style tiles، نمونه‌های اولیه، اول متن    |

## @capture ثبت کنید <a id="capture"></a>

- یافته‌ها، هر کدام با برچسب اصلاح سطحی یا مشکل لایهٔ عمیق‌تر
- تصمیم‌های باز سطح با گزینه‌ها و محدودیت‌ها
- مشکلات میان‌لایه‌ای که باید اول حل شوند
- آنچه از پیش خوب کار می‌کند
