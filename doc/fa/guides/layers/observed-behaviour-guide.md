# راهنمای رفتار مشاهده‌شده

لایهٔ ۱ از ۷، فضای مسئله. مهارت: `/layers-observed-behaviour`.

## بدانید این لایه چیست <a id="know-what-this-layer-is"></a>

- کاربران واقعاً چه می‌کنند، چه گفتند و چه کردند — نه آنچه تیم باور دارد
- سرچشمهٔ همهٔ لایه‌های بالاتر؛ همهٔ لایه‌های دیگر آن را تفسیر می‌کنند

## تصمیم بگیرید <a id="decide"></a>

- کدام ۲ تا ۳ پرسش دربارهٔ کاربران نیاز به پاسخ دارد
- چه شواهدی وجود دارد و چقدر قابل‌اعتماد است
- آنچه کم است چگونه گردآوری شود
- کدام الگوها با اطمینان برقرارند و کدام فرض باقی می‌مانند

## صادق بمانید <a id="keep-it-honest"></a>

- به داده‌های خام نزدیک بمانید: نقل‌قول‌ها، کنش‌ها، احساسات
- هر یافته را مشخص کنید: مشاهده‌شده / استنباط‌شده / فرضی
- شکاف‌های پژوهشی را نام ببرید به‌جای آنکه رویشان سرپوش بگذارید
- راه‌حل‌های موقت (workarounds) را نشانهٔ قوی بدانید

## یک تکنیک برگزینید <a id="pick-a-technique"></a>

| موقعیت                          | تکنیک                                            |
| ------------------------------- | ------------------------------------------------ |
| هنوز پژوهشی نشده                | هدف یادگیری را تعریف کنید، سپس یک مطالعه         |
| محرک‌ها و انگیزه‌ها نامشخص       | مصاحبه‌های JTBD دربارهٔ یک مورد واقعی گذشته        |
| گفتار با کردار فرق دارد         | پرسش در بستر (contextual inquiry)، همراهی (shadowing) |
| محصول موجود                     | تیکت‌های پشتیبانی، داده‌های تحلیلی، کاربردپذیری  |
| مواد موجود است                  | مشاهدات را استخراج و الگوها را گروه‌بندی کنید    |

## ثبت کنید <a id="capture"></a>

- مشاهدات خام کلیدی همراه با منبعشان
- الگوها با شواهد پشتیبان
- داستان‌های کار نامزد (job stories) با میزان اطمینان
- شکاف‌های پژوهشیِ نام‌برده

## ادامه دهید <a id="continue"></a>

داستان‌های کار نامزد را در لایهٔ [نیازهای کاربر](user-needs-guide.md)
پالایش کنید؛ اسم‌هایی را که شنیدید به لایهٔ [دامنه](domain-guide.md)
بدهید.
