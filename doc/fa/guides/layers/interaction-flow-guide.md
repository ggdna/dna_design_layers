# راهنمای جریان تعامل

لایهٔ ۶ از ۷، فضای راه‌حل. مهارت: `/layers-interaction-flow`.

## بدانید این لایه چیست <a id="know-what-this-layer-is"></a>

- مکان‌هایی که کاربر از آن‌ها عبور می‌کند، امکان‌های کنش (affordances) در
  هر کدام، محتوای نمایش‌داده‌شده، جریان میان وضعیت‌ها
- بالای مدل (آنچه وجود دارد)، زیر سطح (ظاهر آن)
- همیشه برای یک کاربر در یک موقعیت که یک کار (job) انجام می‌دهد

## تصمیم بگیرید <a id="decide"></a>

- جریان از کدام مکان‌ها می‌گذرد
- کاربر در هر مکان چه کاری می‌تواند بکند، و به کجا می‌رسد
- هر مکان چه محتوایی نشان می‌دهد
- در حالت خطا، حالت خالی و موارد مرزی چه اتفاقی می‌افتد
- آیا جریان تا حد ممکن ساده است

## صادق بمانید <a id="keep-it-honest"></a>

- هر امکان کنش مقصدی نام‌دار دارد
- موارد مرزی گام‌های الزامی‌اند: اعتبارسنجی، خطای سرور، قطع اتصال، پایان
  مهلت، ویرایش هم‌زمان، خالی، بارگذاری، پس از کنش، لغو
- بدون اشیای گسسته: ویژگی‌ها و کنش‌های یک شیء کنار هم می‌مانند
- بدون اشیای منزوی: هر رابطه قابل پیمایش است یا آگاهانه نیست
- واژگان با زبان فراگیر (ubiquitous language) مطابقت دارد
- مکان‌ها را برای کاربران نام‌گذاری کنید؛ بیش از ۵ تا ۶ مکان برای هر کار یک
  هشدار است

## یک تکنیک برگزینید <a id="pick-a-technique"></a>

| موقعیت                           | تکنیک                                         |
| -------------------------------- | --------------------------------------------- |
| پیش‌فرض                          | طرح‌ریزی اولیه (breadboarding)                |
| یافتن تصمیم‌های گرفته‌نشده       | جریان را در نقش کاربر مرور کنید               |
| برنامه‌ریزی زیاد، کاربران فراوان | نقشه‌برداری داستان کاربر (user story mapping) |
| بازطراحی                         | تحلیل وظیفه                                   |
| کانال‌ها و پشت صحنه              | نقشهٔ خدمت (service blueprinting)             |
| فقط برای جهت‌یابی                | نمودار جریان (`graph LR`)                     |

نشانه‌گذاری breadboard:

```text
Place name
- affordance → destination place
[ content shown in this place ]
```

## ثبت کنید <a id="capture"></a>

- breadboard: مکان‌ها، امکان‌های کنش، مقصدها، محتوا، شرایط
- یک نمودار جریان، اگر به جهت‌یابی کمک کند
- تصمیم‌های باز و موارد مرزیِ حل‌نشده
- ریسک‌هایی که به لایه‌های پایینیِ تثبیت‌نشده وابسته‌اند
